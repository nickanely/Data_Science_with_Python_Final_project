# Financial Market Analysis

A team project analysing 25 years of daily stock data (November 1999 – December 2024) for **NVIDIA (NVDA)** and **Apple (AAPL)**. Stock and transaction data are processed, cleaned and explored (feature engineering, outlier and anomaly detection) and feed price-prediction models (Linear Regression, Random Forest).

## Pipeline

```
Alpha Vantage API ──► stock_data_processor.py ──► data/<SYMBOL>/stock_cleaned_data.csv
                                                        │
                ┌───────────────────────────────────────┼──────────────────────────────┐
                ▼                                       ▼                              ▼
generate_transactions_data.py              stock_data_eda.py               stock_price_predictor.py
   (transaction data)                    (EDA + risk analysis)           (Linear Regression, Random Forest)
                │
                ▼
transactions_data_processor.py
   (merge, clean, Isolation Forest anomaly detection, report)
```

### 1. Data collection and validation (`stock_data_processor.py`)
- Fetches daily price data from the Alpha Vantage API.
- Validates and cleans it: type conversion, missing values, duplicate removal, and price-consistency checks (positive prices; Low ≤ Open, Close ≤ High). Writes a validation report and logs.
- Custom exceptions (`exceptions.py`) separate API errors from data-processing errors.

### 2. Feature engineering and exploratory analysis (`stock_data_eda.py`)
- **Engineered features:** 50- and 200-day moving averages, daily and cumulative returns, 30-day rolling annualised volatility, and the 14-day Relative Strength Index (RSI).
- **Analysis:** descriptive statistics, distribution analysis, time-series analysis, correlation heatmaps, and seasonal decomposition with a 252-trading-day period.
- **Risk analysis:** rolling volatility, RSI with overbought/oversold thresholds, cumulative returns, and daily-return outliers.

### 3. Transaction processing and anomaly detection (`transactions_data_processor.py`)
- Merges transaction-level data with daily stock data, then removes duplicates, fills gaps, enforces numeric types and computes transaction value.
- Detects anomalous transactions with an **Isolation Forest** (200 trees) on transaction value, price, volume and quantity.
- Visualises anomalies and writes a statistical report for each stock.

Transaction data is generated by `generate_transactions_data.py`: 100 trades per trading day within each day's price range.

### 4. Price prediction (`stock_price_predictor.py`)
- **Engineered features:** daily range, average price and 5-day rolling average, with correlation-based feature selection.
- **Linear Regression** and **Random Forest** models, evaluated with MSE and R², with prediction-vs-actual plots.

## Outputs

For each stock, `reports/NVDA/` and `reports/AAPL/` contain the time-series, distribution, correlation, seasonal decomposition and risk-analysis plots, anomaly visualisations, model comparison plots, and statistics reports.

## How to run

```bash
git clone https://github.com/nickanely/Data_Science_with_Python_Final_project.git
cd Data_Science_with_Python_Final_project
pip install -r requirements.txt
```

1. Set your Alpha Vantage API key in `stock_data_processor.py` (`API_KEY`), then download and clean the data for NVDA and AAPL:
   ```bash
   python stock_data_processor.py
   ```
2. Generate transaction data. The symbol is set at the bottom of the script; run it once for each stock.
   ```bash
   python generate_transactions_data.py
   ```
3. Run the analyses:
   ```bash
   python stock_data_eda.py
   python transactions_data_processor.py
   python stock_price_predictor.py
   ```
